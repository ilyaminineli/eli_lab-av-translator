Windows setup and operation

Prepare the performance computer, launch the application, and verify the visual output before a show.

01 — Target system

  • Windows 11, 64-bit.
  • Graphics driver supporting OpenGL 3.3 Core Profile.
  • SSD storage; NVMe is recommended for larger footage libraries.
  • HDMI or supported USB-C DisplayPort output for a projector.
  • Sonic Pi installed separately when using SONATA Expanded.
  • H.264 MP4 footage recommended for initial validation.

For multi-deck performance, 32 GB RAM is recommended, especially with integrated graphics. 16 GB may be sufficient for lighter sessions. Four simultaneous high-bitrate 4K streams are not guaranteed on an integrated GPU.

02 — Install the one-file executable

  1. Obtain the Windows x64 executable from a trusted release or build artifact.
  2. Copy it to a local folder on the performance computer.
  3. Double-click to start it. On first launch, allow time for extraction and Windows Defender scanning.
  4. Writable data, the media database, thumbnails and logs are created under %LOCALAPPDATA%\eli_lab\AV Translator\.

The target computer does not need Python, pip, PyInstaller or FFmpeg. Sonic Pi, graphics/audio drivers, user video files and user-added asset folders are not included in the executable.

03 — Japanese interface fonts

Japanese mode prefers Yu Gothic UI, Meiryo UI / Meiryo, MS UI Gothic / MS PGothic / MS Gothic and BIZ UDGothic, then Noto Sans JP and system fallbacks.

Some Windows installations do not include Japanese supplemental fonts by default. When Japanese text appears as empty squares or boxes:

  1. Open Settings → System → Optional features.
  2. Choose View features beside Add an optional feature.
  3. Search for and install Japanese Supplemental Fonts.
  4. Restart AV Translator so Qt can refresh the available font list.

You can open the page directly with ms-settings:optionalfeatures. Installing the fonts does not require changing the Windows display language.

04 — Prepare footage and projects

A .eliav project and an .eliset performance set store composition state and source paths; they do not embed original video files.

  1. Copy video and user-asset folders to the new computer.
  2. Import the folders into the Media Library.
  3. Reassign or relink the four decks and media overlays if absolute paths changed.
  4. Save a fresh project and performance set on the new computer.

05 — Connect the projector

  1. Connect HDMI before opening fullscreen output.
  2. In Windows Display Settings, choose Extend these displays.
  3. Begin validation at 1920×1080, 60 Hz.
  4. Choose View → PROJECTOR OUTPUT → Display N.
  5. Confirm the status bar reports the active projector renderer and FPS.
  6. Press Escape in the projector output to close it.

Preview and projector use separate OpenGL contexts but share application state. Verify the exact laptop, GPU and projector combination before a production-critical show.

06 — Launch an autonomous performance

  1. Prepare a composition with video decks and/or generator layers.
  2. In AUD / CTRL choose System Loopback for actual audio-band and onset analysis, or Sonic Pi macros when local capture is unavailable or unnecessary.
  3. In AUTO PERF choose a style, musical sync and duration.
  4. Press PERF MODE.
  5. Run SONATA Expanded in Sonic Pi.
  6. Confirm the application moves from ARMED to LIVE and receiver/audio status is healthy.
  7. Open projector output. Stop SONATA to end the AUTO pass, then press STOP PERF MODE when finished.

07 — Diagnostics and troubleshooting

The one-file build supports --self-check. It checks required package imports, FFmpeg availability, H.264 decoding and bundled resources, but does not initialize OpenGL or test HDMI output.

  • OpenGL fails: update the graphics driver and confirm OpenGL 3.3 Core Profile support.
  • Playback drops frames: begin with one or two 1080p H.264 clips, use a local SSD, connect AC power and compare decode/upload counters.
  • Audio loopback unavailable: refresh Windows input devices. Sonic Pi transport and macros can still work, but true band/onset analysis needs loopback.
  • Projector on wrong display: confirm Extend mode, reopen output after display changes, and verify supported refresh rates.
  • Media missing: project files store paths; copy original folders and re-import/reassign them.

The application log is stored under %LOCALAPPDATA%\eli_lab\AV Translator\logs\av-translator.log.
