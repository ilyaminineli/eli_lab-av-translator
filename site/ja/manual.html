操作マニュアル

初回起動からプロジェクター出力まで。

01 — インストールと起動

Windows 11 x64とOpenGL 3.3 Core Profile対応のグラフィックスドライバーが必要です。GitHub Releasesから最新ビルドを入手してください。

02 — 映像素材を準備する

  1. 映像をローカルフォルダーにまとめます。最初はH.264 MP4の720pまたは1080pを推奨します。
  2. PREPAREを開き、Media Libraryにフォルダーを追加します。
  3. 索引作成とサムネイル生成を待ちます。
  4. 4つの動画デッキにクリップを読み込みます。
  5. 元の動画ファイルはプロジェクトに埋め込まれません。

03 — ビジュアルを構成する

COMPOSEでジオメトリ、波形、パーティクル、Text Art、画像・動画オーバーレイを追加します。レイヤーの変形、不透明度、合成モード、エフェクトを調整します。

04 — 音楽に反応させる

6つのPerformance Macro、LFO、エンベロープ、ステップ、フォロワーを利用します。音声解析は物理入力またはシステムループバックを使用します。MIDI機器から操作することもできます。

05 — Sonic Piを接続する

AV Translatorは/eli_lab/v1 OSCプロトコルを受信します。Sonic Piは音楽再生を担当し、AV Translatorはトランスポート、キュー、マクロ情報を使って映像を制御します。同じPCなら127.0.0.1から始めてください。

06 — ライブセットを構成する

VJシーンでビジュアル状態を保存・呼び出しできます。ライブタイムラインは小節とビートを基準にマーカーやアクションを予約します。Performance ModeはSonic Pi自体を起動しません。

07 — プロジェクターに出力する

  1. 出力を開く前にプロジェクターを接続します。
  2. Windowsのディスプレイ設定を「表示画面を拡張する」にします。
  3. View → PROJECTOR OUTPUTから出力先を選択します。
  4. 実際のPCとプロジェクターで解像度、リフレッシュレート、長時間動作を確認します。

08 — プロジェクトの保存と移動

.eliavは構成とプロジェクト状態を保存し、.elisetはパフォーマンスセットを保存します。元の動画や画像は別に管理します。別PCへ移す場合は素材フォルダーもコピーしてください。
