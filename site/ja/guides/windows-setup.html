Windows セットアップと操作

パフォーマンス用PCを準備し、アプリケーションを起動して、本番前に映像出力を確認します。

01 — 対象システム

  • Windows 11、64-bit。
  • OpenGL 3.3 Core Profile対応のグラフィックスドライバー。
  • 映像ライブラリが大きい場合はSSD、できればNVMe。
  • プロジェクター用のHDMIまたは対応USB-C DisplayPort出力。
  • SONATA Expandedを使う場合はSonic Piを別途インストール。
  • 最初の動作確認にはH.264 MP4素材を推奨。

複数デッキを使う場合は32 GB RAMを推奨します。軽いセッションでは16 GBでも十分な場合があります。内蔵GPUで高ビットレートの4K映像を4本同時に再生できる保証はありません。

02 — 実行ファイルのインストール

  1. 信頼できるリリースまたはビルド成果物からWindows x64版EXEを入手します。
  2. パフォーマンス用PCのローカルフォルダーへコピーします。
  3. ダブルクリックで起動します。初回起動では展開とWindows Defenderの確認に時間がかかる場合があります。
  4. 書き込み可能なデータ、メディアDB、サムネイル、ログは%LOCALAPPDATA%\eli_lab\AV Translator\に作成されます。

実行PCにPython、pip、PyInstaller、FFmpegは不要です。Sonic Pi、グラフィックス／オーディオドライバー、ユーザーの動画素材、追加アセットフォルダーはEXEに含まれません。

03 — 日本語インターフェースのフォント

日本語モードではYu Gothic UI、Meiryo UI / Meiryo、MS UI Gothic / MS PGothic / MS Gothic、BIZ UDGothicを優先し、その後Noto Sans JPとシステムフォントへフォールバックします。

Windowsの構成によっては、日本語の追加フォントが標準インストールされていません。日本語が□や空の四角で表示される場合：

  1. 設定 → システム → オプション機能を開きます。
  2. 「オプション機能を追加」の横にある機能を表示を選びます。
  3. Japanese Supplemental Fontsを検索してインストールします。
  4. Qtが利用可能なフォントを再検出できるよう、AV Translatorを再起動します。

ms-settings:optionalfeaturesから直接開けます。Windowsの表示言語を日本語に変更する必要はありません。

04 — 映像素材とプロジェクトの準備

.eliavプロジェクトと.elisetパフォーマンスセットには構成状態と素材パスが保存されます。元の動画ファイルは埋め込まれません。

  1. 動画・ユーザーアセットのフォルダーを新しいPCへコピーします。
  2. Media Libraryにフォルダーを登録します。
  3. 絶対パスが変わった場合は4つのデッキとメディアオーバーレイを再割り当て／再リンクします。
  4. 新しいPCでプロジェクトとパフォーマンスセットを保存します。

05 — プロジェクター接続

  1. フルスクリーン出力を開く前にHDMIを接続します。
  2. Windowsのディスプレイ設定で表示画面を拡張するを選びます。
  3. 最初は1920×1080、60 Hzで確認します。
  4. View → PROJECTOR OUTPUT → Display Nを選択します。
  5. ステータスバーでプロジェクターレンダラーとFPSを確認します。
  6. 出力画面でEscapeを押すと閉じます。

プレビューとプロジェクターは独立したOpenGLコンテキストを使いますが、アプリケーション状態を共有します。本番前に実際のPC、GPU、プロジェクターの組み合わせで確認してください。

06 — 自動パフォーマンスの開始

  1. 動画デッキまたはジェネレーターレイヤーを使って構成を準備します。
  2. AUD / CTRLで、実際の音声帯域・オンセット解析にはSystem Loopbackを選びます。ローカルキャプチャが不要な場合はSonic Piマクロを使用します。
  3. AUTO PERFでスタイル、音楽同期、再生時間を選びます。
  4. PERF MODEを押します。
  5. Sonic PiでSONATA Expandedを実行します。
  6. 状態がARMEDからLIVEへ変わり、OSC／音声が正常であることを確認します。
  7. プロジェクター出力を開きます。SONATAを停止してAUTOパスを終了し、最後にSTOP PERF MODEを押します。

07 — 診断とトラブルシューティング

パッケージ版は--self-checkに対応します。必要パッケージ、FFmpeg、H.264デコード、同梱リソースを確認しますが、OpenGL初期化やHDMI出力は検証しません。

  • OpenGLが起動しない：グラフィックスドライバーを更新し、OpenGL 3.3 Core Profile対応を確認します。
  • 再生が遅い：まず1080p H.264を1〜2本で確認し、ローカルSSDとAC電源を使用してデコード／アップロードの負荷を確認します。
  • ループバックが使えない：Windowsの入力デバイス一覧を更新します。Sonic Piのトランスポートとマクロは動作しますが、実音声の帯域・オンセット解析にはループバックが必要です。
  • プロジェクターが別画面に出る：拡張表示を確認し、ディスプレイ構成変更後に出力を開き直します。
  • メディアが見つからない：プロジェクトはパスを保存します。元フォルダーをコピーして再登録／再割り当てします。

ログは%LOCALAPPDATA%\eli_lab\AV Translator\logs\av-translator.logに保存されます。
