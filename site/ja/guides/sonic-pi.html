Sonic Pi / SONATA 接続

Sonic Piを音楽のクロックとコントロールソースとして使い、AV Translatorで映像を演奏します。

01 — 接続の役割

SONATA Expandedはトランスポート、小節クロック、シーン、マクロ、キュー、ハートビートを送信します。AV Translatorはバージョン付きOSC名前空間/eli_lab/v1で受信します。音声再生はSonic Piが担当し、AV Translatorは音楽的な情報を使って映像シーンやパラメーターを変化させます。

M4送信処理は音楽的な制御ポイントのみに追加されています。93個のシンセ／ドラムループ自体には介入しません。

02 — 送信設定

SONATA_expanded.rbの先頭で次の値を確認します。

  • $sp_av_enabled = true — 音声のみでリハーサルする場合はfalse。
  • $sp_av_host = "127.0.0.1" — AV Translatorのアドレス。
  • $sp_av_port = 57121 — AUD / CTRLに表示される受信ポートと合わせます。

同じPCで使う場合はループバックが初期値です。別PCのSonic Piから送る場合は、AV Translator側をLANから到達できるIPv4アドレスにバインドし、$sp_av_hostにも同じアドレスを指定します。リモート送信で127.0.0.1は使わないでください。

03 — ワンボタン自動接続

  1. 構成を準備します。実際の音声帯域・オンセット解析にはAUD / CTRLでSystem Loopbackを選びます。ローカルキャプチャが利用できない場合はSonic Piマクロを使用します。
  2. 受信アドレスとポートを確認します。COPY SONATA SETTINGSでパッチへコピーできます。
  3. PERF MODEを押します。AV TranslatorはOSC受信機を開始または再利用し、必要な音声キャプチャ、デフォルトのモジュレーションカーブ／ルートを準備して自動演奏をアームします。
  4. Sonic PiでSONATA_expanded.rbを実行します。
  5. 最初のtransport/startまたは受理された小節クロックでARMEDからLIVEへ切り替わります。シーン、フレーズキュー、マクロ値が映像を変化させます。
  6. SONATAを停止すると自動演奏が停止します。最後にSTOP PERF MODEを押してモードが所有するリソースを解放します。

最後のendマーカーを含む16回のシーン変更

小節クロックはsp_b_countを増やしてsp_bをcueし、その後4ビート待機します。シーン変更ではsp_scとsp_intを更新してsp_sc_changeをcueします。マクロループはenergy、cutoff、phrase indexを更新します。OSCのbar_indexは1始まりで、最初のクロック前のシーンマーカーのみ0を使います。

05 — OSCプロトコル

すべてのイベントはセッションID文字列と正のシーケンス番号から始まります。シーケンス番号は1回のパッチ実行中、イベント種別に関係なく増加します。パッチを再起動すると新しいセッションIDが生成されます。

内蔵マクロ名はchaos、density、depth、decay、pressure、fragmentです。既存のパッチは正規化されたenergyとcutoffも送信します。受信側は値と名前を検証し、未知の名前や範囲外の値を拒否します。

06 — 受信側の安全性

  • 初期バインドはループバックです。別インターフェースは明示的に選択します。
  • 既知のアドレス、正確な引数数、OSC型、数値範囲のみ受け付けます。
  • 有界の再送履歴で古いセッション、重複、順序違いのパケットを拒否します。
  • 入力は初期値で毎秒60メッセージに制限されます。
  • OSCワーカーは検証済みイベントをキューへ送ります。Qtウィジェット、構成状態、OpenGLリソースをワーカーから直接操作しません。
  • 送信がstaleになった場合はSONATAを新しいセッションIDで再起動します。

07 — リハーサル確認

  1. AV Translatorを起動してPERF MODEを押し、指定アドレス／ポートで受信していることを確認します。
  2. SONATAを実行し、ARMEDからLIVEへ変わることを確認します。
  3. BPM 92、小節1〜384、シーン変更、energy/cutoff、フレーズキューを確認します。
  4. SONATAを再起動し、新しいセッションが受理され、古いセッションの遅延パケットが拒否されることを確認します。
  5. STOP PERF MODEを押してもSonic Piの音声が続くことを確認します。次の実行前に再アームします。

プロトコルと送信処理の実装は完了していますが、384小節の全編は対象のSonic Pi／AV Translator環境で手動リハーサルが必要です。
