Field manual

From a first launch to a projector-ready performance.

01 — Install and launch

The packaged application targets Windows 11 x64 and a graphics driver supporting OpenGL 3.3 Core Profile. Download the latest build from GitHub Releases. Development setup is documented in Windows setup.

02 — Prepare footage

  1. Collect source videos in local folders. Start with H.264 MP4 at 720p or 1080p.
  2. Open PREPARE and add a folder to the Media Library.
  3. Wait for indexing and thumbnails.
  4. Load clips into the four independent video decks.
  5. Keep the source folders; project files store paths and composition state, not embedded media.

03 — Build a composition

In COMPOSE add geometry, waveforms, particles, Text Art and image/video overlays. Shape layers with transforms, opacity, blend modes and per-layer effects. See Generative visuals and Typography.

04 — Shape the image with performance controls

Use six normalized Performance Macros, LFOs, envelopes, steps and followers. Audio analysis can use a physical input or system loopback. MIDI maps hardware controls to performance targets.

05 — Connect Sonic Pi

AVTranslator receives versioned OSC messages at /eli_lab/v1. Sonic Pi remains responsible for music playback; AVTranslator uses transport, cues and macro messages to shape visuals. Start with 127.0.0.1 for same-computer use. See the Sonic Pi / SONATA integration guide.

06 — Structure a set

Capture and recall VJ scenes. Use the live timeline to schedule markers and actions by bar and beat. Performance Mode arms external controls and AUTO PERF; it does not start Sonic Pi itself.

07 — Project the image

  1. Connect the projector before opening output.
  2. Set Windows to Extend these displays.
  3. Choose View → PROJECTOR OUTPUT.
  4. Validate resolution, refresh rate and GPU behaviour on the actual performance system.

08 — Save and move a project

.eliav stores composition and project state. .eliset stores a performance set. Source media remains external. Copy media folders to the new computer and relink paths when needed.

Troubleshooting and limitations

See Windows setup, Architecture and Roadmap. Automated tests do not replace target-machine checks of OpenGL, four-deck playback, long-duration operation or projector output.
