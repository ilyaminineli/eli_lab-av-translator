About eli_lab AVTranslator

A composition should be something that can be performed, not only something rendered once and finished.

eli_lab AVTranslator is a Windows desktop environment for live audiovisual composition and performance. It brings footage, typography, procedural graphics and visual effects into one system that can respond to sound, musical time, MIDI and OSC.

The project is developed as part of eli_lab by Ilya Minin (Eli).

Project boundaries

AVTranslator is a live visual instrument. It is not a general-purpose non-linear video editor, digital audio workstation or full 3D authoring environment. Sonic Pi remains an external music/playback system; original video and image files remain external to project files.
