# eli_lab AVTranslator について

**映像素材、生成グラフィックス、タイポグラフィを音楽とともに動かす、ライブ映像制作ツール。**

eli_lab AVTranslator は、ライブパフォーマンスのための Windows デスクトップ環境です。動画、テキスト、プロシージャルなグラフィックス、画像オーバーレイ、映像エフェクトを一つの構成にまとめ、音声、リズム、MIDI、Sonic Pi から操作できます。

一般的な動画編集ソフトとは異なり、完成した映像をタイムラインに並べることよりも、演奏中に変化するビジュアルシステムを作ることを目的としています。

## 何ができるか

### 映像素材によるライブコラージュ

最大4つの独立した動画デッキを使って、複数の映像を組み合わせます。各デッキには再生位置、区間、ループ、フレーム保持、ロックの操作があります。メディアライブラリはローカルの映像素材を索引化します。

### 生成素材と映像を重ねる

構成には動画、画像オーバーレイ、アニメーション画像、ジオメトリ、波形、テキスト、GPUパーティクルを追加できます。レイヤーの位置、拡大縮小、合成モード、順序を調整し、マスターエフェクトやレイヤー別のエフェクトスタックを適用できます。

### 文字を映像の一部として扱う

Text Art は複数行テキスト、スタイル付きテキスト、横書き・縦書き、パスに沿った配置、アニメーション表現に対応します。英語と日本語のテキストプールも利用できます。

### 音と時間に反応させる

音声入力またはシステムループバックを解析し、レベル、ピーク、周波数帯、オンセット、テンポなどを利用できます。6つの正規化された Performance Macro は複数のビジュアルパラメーターを同時に制御できます。LFO、エンベロープ、ステップ、フォロワーなどのモジュレーターも使用できます。

### Sonic Pi、MIDI、シーンで演奏する

OSC の `/eli_lab/v1` プロトコルを通じて、Sonic Pi からトランスポート、キュー、マクロ情報を受信できます。MIDI とキーボードによる操作にも対応します。VJ シーンと小節／ビートのタイムラインによって、固定された動画編集にせずにライブセットを構成できます。

### スクリーンやプロジェクターに出力する

ローカルプレビューとフルスクリーンのプロジェクター出力を利用できます。両者は同じ構成状態を共有しながら、独立したグラフィックスリソースを使用します。

## 3つのワークスペース

**PREPARE — 素材を準備する。** 映像を読み込み、メディアライブラリを整理し、ビジュアル素材を探します。

**COMPOSE — ビジュアルを構成する。** レイヤー、ジェネレーター、テキスト、オーバーレイ、合成、エフェクトを組み合わせます。

**PERF — 構成をライブで操作する。** デッキ、マクロ、シーン、音声／Sonic Pi の入力を使い、プロジェクターへ出力します。

## どんな人に向いているか

- **VJ・ライブ映像パフォーマー:** 4デッキ、コラージュ、レイヤー、エフェクト、シーン、マクロ、プロジェクター出力。
- **電子音楽家・Sonic Pi ユーザー:** 音楽と同期するOSC制御のビジュアル。
- **映像・メディアアーティスト:** 撮影素材とプロシージャルな表現を組み合わせたライブ作品。
- **ジェネラティブアーティスト:** 生成表現をライブで操作するための構成・パフォーマンス環境。
- **タイポグラフィを使うアーティスト:** 英語・日本語の文字、縦書き、アニメーション文字による作品。

## 向いていない用途

- 従来型のノンリニア動画編集や仕上げ作業。
- DAW、楽器、ミキサー、マスタリングなどの音声制作。
- フル機能の3Dシーン制作。
- 完成した映像・音声マスターの録画や書き出し。

このソフトウェアは、動画編集ソフトやDAWの代替ではなく、ライブ映像を構成・演奏するためのツールです。

## システム要件

パッケージ版は **Windows 11 x64** を対象とし、**OpenGL 3.3 Core Profile** に対応するグラフィックスドライバーが必要です。

軽い構成では16 GB RAMから利用できます。複数デッキを使う場合、特に内蔵GPUでは32 GB RAMを推奨します。最初はH.264の720pまたは1080p素材で動作を確認してください。高ビットレートの4K動画を4本同時に再生できることは保証されません。

Sonic Pi、映像素材、ユーザー追加の素材フォルダーは別途インストール／用意してください。

## ファイルとプロジェクト

`.eliav` プロジェクトと `.eliset` パフォーマンスセットには、構成設定とメディアパスが保存されます。元の動画ファイルは埋め込まれません。別のPCに移す場合は、素材フォルダーもコピーして再読み込みまたは再リンクしてください。
