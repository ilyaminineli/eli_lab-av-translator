# About eli_lab AV Translator

eli_lab AV Translator is a Windows desktop environment for live audiovisual composition and performance. It brings footage, typography, procedural graphics and visual effects into one system that can respond to sound, musical time, MIDI and OSC.

The project is developed as part of **eli_lab** by **Ilya Minin (Eli)**.

Its central idea is simple: a visual composition should be something that can be performed, not only something that is rendered once and finished.

The software is open source. The source code, issue tracker and current releases are available in the [GitHub repository](https://github.com/ilyaminineli/eli_lab-av-translator).

## Project boundaries

AV Translator is a live visual instrument. It is not a general-purpose non-linear video editor, digital audio workstation or full 3D authoring environment. Sonic Pi remains an external music/playback system; original video and image files remain external to `.eliav` project files.

See the [Product overview](PRODUCT_OVERVIEW.md) for audience fit and capability boundaries.
